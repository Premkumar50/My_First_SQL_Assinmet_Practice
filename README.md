## 📊 Database Table

The project uses an `employeex` table with the following columns:

| Column | Description |
|---|---|
| employee_id | Unique employee ID |
| first_name | Employee's first name |
| last_name | Employee's last name |
| department | Employee's department |
| salary | Employee salary |
| joining_date | Employee joining date |
| age | Employee age |

## 📝 Assignment Questions

### Q1. Retrieve all employees' first names and their departments.

### Q2. Update the salary of employees in the IT department.

### Q3. Delete employees who are older than 34 years.

### Q4. Add a new `email` column to the employee table.

### Q5. Rename the `department` column.

### Q6. Retrieve employees who joined after January 1, 2021.

### Q7. Change the data type of the salary column to INTEGER.

### Q8. List employees with their age and salary in descending order of salary.

### Q9. Insert a new employee into the table.

### Q10. Increase the age of every employee by 1.
